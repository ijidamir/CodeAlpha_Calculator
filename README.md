CodeAlpha Calculator
A simple and responsive web-based calculator built as part of my internship tasks at CodeAlpha. This project demonstrates core front-end development skills, including DOM manipulation, event handling, and UI design.
🚀 Features
Basic arithmetic operations:
Addition (+)
Subtraction (−)
Multiplication (×)
Division (÷)
Percentage (%) calculation
Modulus (%) operation
Clear button (C) to reset all inputs
Delete button (⌫) to remove the last digit
Real-time display updates
Responsive and user-friendly interface
🛠️ Built With
HTML5 – Structure of the calculator
CSS3 – Styling and layout
JavaScript (Vanilla JS) – Functionality and logic
📂 Project Structure

code-alpha-calculator/
│── index.html
│── style.css
│── script.js
│── README.md
⚙️ How It Works
User inputs are captured through button clicks.
JavaScript handles all operations dynamically.
Mathematical expressions are evaluated and displayed instantly.
Special functions:
C (Clear): Resets the calculator
DEL (Delete): Removes the last entered character
